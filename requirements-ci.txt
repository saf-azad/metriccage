# CI-only dependency set — deliberately slimmer than requirements.txt to keep CI fast.
#
# Included: everything src/ and tests/ import at collection/runtime that is cheap to
# install (core scientific stack, classical ML, scraping libs used by src/data, plotting
# for report scripts, test + lint tooling).
#
# Excluded on purpose:
#   - torch/torchmetrics: ~2 GB of wheels; torch is optional at import time in src/api
#     (guarded by try/except) — the LSTM stream simply disables itself without it.
#   - jupyterlab, mlflow, optuna: notebook/experiment-tracking/HPO tooling, unused by
#     `ruff check`, `mypy src`, and `pytest tests/`.
#   - plotly, seaborn: interactive/statistical viz used only in notebooks and local
#     report generation; matplotlib covers the scripted plots.
#
# Data-dependent tests skip in CI via the `requires_data` marker (tests/conftest.py),
# so no parquet/pickle artifacts are needed here either.
